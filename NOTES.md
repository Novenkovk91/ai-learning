### Задачи на доработку

#### Срок выполнения (`end_date`) и команда `urgent` в `day3_todo_cli.py`

**Серьёзность:** Идея. Добавлено 2026-11-16.

Два отдельных этапа, на каждый свой коммит.

**Этап 1. Поле `end_date` (срок).** Зачем: видеть, к какому сроку нужно сделать задачу.
- В `todo.json` хранить в формате ГГГГ-ММ-ДД, на экране показывать как ДД.ММ.ГГГГ.
- Текущим задачам проставить: №1 — 20.11.2026, №2 — 22.11.2026, №3 — 24.11.2026, остальным — сегодня + 7 дней. Перед изменением `todo.json` сделать резервную копию.
- `add "Текст"` — срок по умолчанию сегодня + 7 дней; `add "Текст" --due 25.11.2026` — свой срок.
- Неверная дата — понятное сообщение, задача не создаётся.
- `list` показывает новую колонку «Срок».

**Этап 2. Команда `urgent`.** Зачем: быстро увидеть самую срочную задачу.
- Показывает невыполненные задачи с самым ранним сроком (включая просроченные) таблицей: №, Задача, Статус, Ответственный, Срок.
- Если таких задач несколько — показывает все.
- Просроченные помечает «просрочено».
- Если невыполненных задач нет — сообщение «Срочных задач нет».
- `urgent` ничего не меняет в `todo.json`.

**Готово, когда:** оба этапа работают по описанию; `add` без `--due`, `done`, `owner` работают как раньше.
**Можно менять:** `day3_todo_cli.py` и описание формата задачи в `CLAUDE.md`.
**Нельзя:** коммитить без одобрения владельца.
**Порядок:** сначала план, потом реализация. Делай по одному этапу: после Этапа 1 остановись для приёмки, к Этапу 2 переходи только по моей команде.

## Принятые решения

- **2026-11-13.** Проверка номера задачи вынесена в общую функцию `get_task` в `day3_todo_cli.py`, её используют `done` и `owner` (вариант А вместо копирования кода). Поведение `done` при этом не изменилось — сверено с выводом до правок.
- **2026-11-13.** Хук проверки синтаксиса `.py` (`.claude/settings.json`) вызывает отдельный скрипт `.claude/hooks/check_py_syntax.py`, а не однострочник прямо в JSON: в Windows кавычки и обратные слеши в однострочнике легко ломаются, а скрипт проще читать и проверять. Ошибку скрипт отдаёт кодом выхода 2 — так Claude Code показывает её модели.
- **2026-11-13.** `owner`: если в файле ответственный записан не текстом (число, список), он приводится к тексту через `str()` для сравнения и вывода, а не считается ошибкой.
